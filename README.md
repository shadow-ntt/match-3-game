# Match-3 Game

Dự án game Match-3 được phát triển bằng Unity.

## 🛠 Yêu cầu hệ thống / Môi trường phát triển

- **Unity Version**: `6000.5.7f1` (Unity 6)
- **Render Pipeline**: Universal Render Pipeline (URP - 2D)

## 🚀 Cài đặt & Chạy dự án

1. Cài đặt Unity Editor phiên bản **`6000.5.7f1`** thông qua Unity Hub.
2. Mở Unity Hub -> **Add** -> Chọn thư mục dự án `match-3-game`.
3. Mở scene chính tại: `Assets/Scenes/SampleScene.unity`.
